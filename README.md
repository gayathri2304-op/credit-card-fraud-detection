# credit-card-fraud-detection
Deep learning ensemble with data resampling for credit card fraud detection.system that uses data resampling techniques such as SMOTE and ADASYN with ensemble learning to handle highly imbalanced transaction data. The system combines multiple models to improve fraud detection, increase recall and F1-score, and reduce false positives.
🚧 Project Status: In Development

This project is currently under development. The machine learning
model, web application, OTP verification, and admin dashboard are
being implemented and tested.
